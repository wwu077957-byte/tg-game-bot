# 🎮 Telegram 中文游戏机器人

纯 Python 标准库实现（Python 3.11+），**无需安装任何依赖**。支持私聊和群聊，内置 11 类小游戏。

> ⚠️ 纯娱乐：不涉及任何金钱、下注或奖品，积分只是好玩，不能兑换任何东西。

## 快速运行

```bash
export BOT_TOKEN="123456:你的机器人Token"   # 必填，只从环境变量读取
export DB_PATH="./gamebot.db"               # 可选，默认 ./gamebot.db
python3 bot.py
```

### Docker

```bash
docker build -t gamebot .
docker run -d --name gamebot --restart unless-stopped \
  -e BOT_TOKEN="123456:你的机器人Token" \
  -e DB_PATH=/data/gamebot.db -v gamebot-data:/data gamebot
```

## 环境变量

| 变量 | 必填 | 说明 |
|---|---|---|
| `BOT_TOKEN` | 是 | 从 @BotFather 获取的 Token（代码中不保存任何 Token） |
| `DB_PATH` | 否 | SQLite 数据库路径，默认 `./gamebot.db`（保存娱乐积分、最佳纪录） |
| `LOG_LEVEL` | 否 | 日志级别，默认 `INFO` |

## 在 @BotFather 里的设置（重要）

1. **关闭隐私模式**：`/setprivacy` → 选择机器人 → `Disable`。
   否则在群里机器人收不到普通文字消息，**猜数字、成语接龙**在群里只能通过“回复机器人的消息”来作答。
   （或者把机器人设为群管理员，也能收到全部消息。）改完后需要把机器人移出群再重新拉进来。
2. 允许加入群：`/setjoingroups` → `Enable`（默认就是开启）。
3. 命令菜单无需手动设置，机器人启动时会自动调用 `setMyCommands`。

## 游戏与命令

| 游戏 | 命令 | 说明 |
|---|---|---|
| 🎲 骰子 | `/dice`、`/dice 2d6`、`/dice 比大小` | 单骰用 Telegram 骰子动画；NdM 文本结果；比大小：群里大家点「参加」，发起人点「开始」，点数最大者赢（私聊是你 vs 机器人） |
| 🔮 抽签 | `/draw` | 随机抽上上签/上签/中签/下签 |
| 🤔 随机选择 | `/pick 火锅 烧烤 日料` | 帮你随机选一个（空格、逗号、顿号分隔都行） |
| 🎁 群抽奖 | `/lottery [中奖人数] [标题]` | 群成员点「参加」，发起人点「开奖」，随机抽出中奖者（机器人不发任何奖品；30 分钟未开奖自动取消） |
| 🐺 狼人杀 | `/werewolf` | 群聊 5~12 人。身份：狼人/预言家/女巫/猎人(7人起)/村民。夜晚在私聊点按钮行动，白天讨论后投票。全程有超时；`/endgame` 结束（发起人或管理员） |
| 🕵️ 谁是卧底 | `/undercover` | 群聊 4~10 人（7 人起 2 个卧底），词语私聊发送，轮流描述后投票 |
| 🧠 答题 | `/quiz`、`/quizrank` | 104 道选择题。群里抢答（每人一次机会，第一个答对得分）；私聊为连对模式，记录个人最佳 |
| 🔢 猜数字 | `/guess` | 1~100，提示大了/小了；群里所有人都能猜 |
| 📜 成语接龙 | `/idiom` | 词库 500+ 成语，首字必须与上一个尾字相同（同字），60 秒无人接上本轮结束 |
| ✊ 石头剪刀布 | `/rps` | 私聊对战机器人；群里发 `/rps` 公开挑战，或**回复某人的消息**发 `/rps` 指定对手。出拳只有自己看得到，双方都出完才揭晓 |
| 🎭 真心话大冒险 | `/tod` | 真心话/大冒险各 40+ 条友好安全的题目 |
| 🃏 21点 | `/blackjack` | 和庄家比（庄家 17 点停牌），赢了加娱乐分 |
| ⭕ 井字棋 | `/ttt` | 私聊对战机器人；群里双人对战（可回复某人指定对手） |
| 🏆 积分榜 | `/rank` | 本群所有游戏的娱乐积分总榜 |
| 其他 | `/start`、`/help`、`/cancel`、`/endgame` | `/cancel` 取消本聊天中的游戏（群里需发起人或管理员） |

群里也可以用 `/命令@机器人用户名`，发给其他机器人的命令会被忽略。

### 狼人杀 / 谁是卧底须知
- 每位玩家必须先**私聊机器人发送 /start**，否则机器人无法给你发身份/词语。报名消息里有「私聊机器人」按钮。
- 开始时如果有人无法接收私信，会自动把他移出报名并提醒。
- 所有阶段都有超时（狼人杀：夜晚 90 秒、女巫 45 秒、猎人 40 秒、讨论 120 秒、投票 60 秒），连续两轮无人操作会自动结束，游戏不会卡住。

## 项目结构

```
bot.py              入口：长轮询、429 重试、断线重连、定时器线程
tg.py               Telegram Bot API 封装（urllib）
core.py             应用核心：命令分发、回调、会话、调度器、通用命令
db.py               SQLite：娱乐积分 / 用户是否私聊过 / 最佳纪录
games/              各游戏模块（team.py 为狼人杀、谁是卧底共用的报名与投票流程）
data/               题库、成语、词语对、签文、真心话大冒险
tests/              假 Telegram 服务器 + 全部游戏的自动化测试
```

## 运行测试（不需要 Token，不联网）

```bash
python3 -m unittest discover -s tests -v
python3 -m py_compile bot.py core.py db.py tg.py games/*.py data/*.py
```

## 说明与限制
- 游戏进行中的状态保存在内存里，机器人重启后进行中的对局会丢失（积分在 SQLite 中，不会丢）。
- 只支持单进程运行；同一个 Token 不要同时运行多个实例（会出现 409 冲突）。
- 成语接龙只认同一个字，不支持同音字。
